**The `is_this_safe()` primitive for the Mantle agent economy.**

Multi-LLM smart-contract audit engine with Mantle-native Arsia gas profiling, ERC-8004 on-chain attestation, AES-256-GCM encrypted findings, and a 113-pattern exploit corpus covering **$10.1B** in documented losses (2020–2026).

## Why this exists

Minterest lost $1.4M on Mantle in July 2024 to a reentrancy bug a static analyzer would have flagged. KelpDAO's rsETH bridge lost $292M in April 2026 to a single-DVN LayerZero config TryAnneal's `single-dvn-verifier` detector catches. The agent economy is being built right now — agents will compose with code they didn't write — and no general-purpose audit tool understands Mantle-specific patterns. TryAnneal does.

One HTTP call. Any agent. Any chain. Verdict pulled directly from on-chain.

```bash
BASE=https://tryanneal.xyz
curl "$BASE/api/safety/$(cast keccak "$(cat YourContract.sol)")"
# → {"safe": false, "score": 40, "criticalCount": 1, "highCount": 2, ...}
```

## What it does

- **Multi-LLM audit cascade.** ChainGPT pre-screen (~4 s) → Gemini 2.5 Pro + Groq Llama-3.3-70B + **Tencent Cloud Hunyuan-Turbos** critics fan out in parallel. Hunyuan is the Tencent Cloud integration for the DevTools track — visible in the `Models used` line on every audit output.
- **15 custom Slither detectors.** Agent-context (ERC-8004 reentrancy + callback loops), Mantle-specific (Arsia anti-patterns, calldata-bloat, L1Block unchecked reads, operator-fee outliers), and exploit-pattern detectors for KelpDAO/LayerZero DVN, Euler donation, Nomad init, oracle staleness, AMM spot-oracle dependency, signature replay, approval-abuse arbitrary calls, vault-share rounding.
- **113-pattern exploit corpus.** Regenerated by [`build_corpus.py`](./packages/detectors/tryanneal_detectors/corpus/build_corpus.py) from raw research dumps. TF-IDF cosine similarity + vulnerability-class boost + detection-difficulty downgrade surface matches like *"your code is 78% similar to the $292M KelpDAO drain — linked to Radiant Capital Oct 2024 (DPRK Citrine Sleet cluster)"*.
- **Arsia gas profiler (post-upgrade accurate).** Live `L1Block` predeploy reads, 3-provider RPC consensus, FastLZ-sized L1 data fee, operator-fee scalar, MNT-native (no retired `tokenRatio` selector).
- **ERC-8004 on-chain attestation.** TryAnneal is a registered ERC-8004 agent on Mantle mainnet (**agentId 131**). Every verdict posts to `AnnealValidation` (mainnet + Sepolia). Anyone reads it via `getVerdict(codeHash)` or the safety oracle API.
- **AES-256-GCM encrypted findings.** Decryption key returned once. TryAnneal never stores it. Destroy the key → crypto-shredded report. Verdict score stays public; vulnerability details stay private.
- **Auditor staking with slashing.** 7-day cooldown, 2.5%/10% slash floor/cap, 60/30/10 fee split.
- **CI/CD ready.** [`.github/workflows/anneal-audit.yml`](./.github/workflows/anneal-audit.yml) runs the engine on every PR that touches Solidity and posts the verdict as a PR comment.

## Quick start

```bash
pnpm install

# Slither-only audit (no API keys needed)
cd packages/cli
npx anneal audit ../contracts/contracts/audit-targets/SampleVault.sol --no-llm

# Full LLM cascade — ChainGPT pre-screen, Gemini + Groq + Hunyuan critics
CHAINGPT_API_KEY=... GEMINI_API_KEY=... GROQ_API_KEY=... HUNYUAN_API_KEY=... \
  npx anneal audit ./MyContract.sol

# Audit + on-chain attestation + encrypted Arweave storage
DEPLOYER_PRIVATE_KEY=0x... \
ANNEAL_AGENT_ID=42 \
  npx anneal audit ./MyContract.sol --attest \
    --validation 0x...AnnealValidation
```

CLI flags:

| flag | effect |
|---|---|
| `--quick` | ChainGPT pre-screen only, skip the critic cascade |
| `--no-llm` | Static analysis only (Slither + Aderyn + corpus), no API calls |
| `--no-aderyn` | Skip the Aderyn (Rust) static-analysis layer |
| `--gas-only` | Skip security audit, only profile gas |
| `--attest` | Post verdict on-chain via `AnnealValidation.postVerdict` |
| `--no-encrypt` | Skip AES-GCM encryption / report storage |
| `--reports-dir <dir>` | Local fallback dir for encrypted reports |
| `-n, --network` | `mantle` (mainnet) or `mantle-sepolia` |

Full flag reference and demo recipes: [docs/CLI_GUIDE.md](docs/CLI_GUIDE.md).

## Custom detectors

15 detectors live in [`packages/detectors/`](./packages/detectors). Once `pip install -e packages/detectors` runs, Slither loads them automatically.

```bash
anneal audit Vault.sol --detectors=tryanneal    # only the custom pack
anneal audit Vault.sol --detectors=builtin      # only stock Slither
anneal audit Vault.sol                          # default: both
```

See [`packages/detectors/README.md`](./packages/detectors/README.md) for the full inventory.

Audit flow:

```
.sol file
   │
   ▼
runAudit() ──► Slither + Aderyn (parallel, best-effort)
   │
   ├─► ChainGPT pre-screen (~4s)
   │      │
   │      └─► no high/critical?  → early return
   │
   ├─► Critic cascade in parallel (≤60s)
   │      ├─ Gemini 2.5 Pro
   │      ├─ Groq Llama-3.3-70B
   │      └─ Tencent Cloud Hunyuan
   │
   ├─► Consensus scorer
   │      ├─ line-overlap dedup
   │      ├─ Slither cross-validation (+15, cap 99)
   │      ├─ single-model floor (33%)
   │      └─ <20% cull
   │      (LLM stage is non-fatal — degrades to static + corpus)
   │
   ├─► Arsia gas profiler (3 RPC providers, 2/3 vote)
   ├─► AES-256-GCM encrypt findings
   └─► AnnealValidation.postVerdict on Mantle
```

## Deploying

```bash
cd packages/contracts
# Sepolia (testnet)
DEPLOYER_PRIVATE_KEY=0x... npx hardhat run scripts/deploy-all.ts --network mantleSepolia
# Mainnet (chain 5000)
DEPLOYER_PRIVATE_KEY=0x... npx hardhat run scripts/deploy-all.ts --network mantleMainnet
```

`deploy-all.ts` deploys `AnnealAgent` → `AnnealValidation` → `AnnealStaking` (WMNT on mainnet, MockERC20 on Sepolia), verifies each on mantlescan, and writes the manifest. On mainnet the script also targets the official ERC-8004 registry; agent registration (`register(string)`) mints a real agentId — TryAnneal is **agentId 131**.

## Running a batch of audits

```bash
cd packages/contracts
DEPLOYER_PRIVATE_KEY=0x... CHAINGPT_API_KEY=... GEMINI_API_KEY=... GROQ_API_KEY=... HUNYUAN_API_KEY=... \
  npx hardhat run scripts/run-audits.ts --network mantleSepolia

# Audit a LIVE mainnet protocol and post the verdict on-chain:
npx hardhat run scripts/audit-live-protocols.ts --network mantleMainnet
```

`run-audits.ts` exercises five fixtures in `contracts/audit-targets/`. `audit-live-protocols.ts` fetches a real protocol's verified source from mantlescan, audits it, and posts the verdict on-chain (default: Merchant Moe LB Router).

## Tech stack

- **Engine** — TypeScript, Slither 0.11.5 + Aderyn (Rust) static analysis, ChainGPT + Gemini 2.5 Pro + Groq Llama-3.3-70B + **Tencent Cloud Hunyuan** LLM cascade
- **Contracts** — Solidity 0.8.24, Hardhat, OpenZeppelin 5, hardhat-verify v2
- **Detectors** — Python Slither plugin (15 custom detectors + corpus meta-detector), scikit-learn TF-IDF corpus matcher
- **Storage** — Arweave (encrypted blobs); local `./reports/{codeHash}.enc` fallback
- **Frontend** — Next.js 16 App Router, TailwindCSS 4
- **Integrations** — `@tryannealbot` Telegram bot, GitHub Actions PR audit, public safety-oracle REST API
- **Test** — Vitest (engine), Hardhat/Mocha (contracts), pytest (detectors)
